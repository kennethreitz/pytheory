PyTheory VST
============

Want to use PyTheory inside your DAW, not just from Python?
`PyTheory VST <https://github.com/kennethreitz/pytheory-vst>`_ is a set of
AU/VST3 plugins that bring the library into Ableton Live and other hosts.

What you get
------------

Four plugins, each with Python bundled inside so there is nothing extra to
install:

- **MIDI** - a scale and chord MIDI effect, driven by PyTheory's key and
  chord logic.
- **Instrument** - an 84-preset sampler built from PyTheory's instrument
  list.
- **Drums** - a kit with PyTheory's 74 synthesized percussion sounds.
- **Effect** - an effects chain matching PyTheory's per-part processing.

Requirements and download
-------------------------

macOS 13 or later on Apple silicon. Grab the AU or VST3 zip from the
`latest release <https://github.com/kennethreitz/pytheory-vst/releases/latest>`_,
drop the plugins into your plug-in folders, and rescan in your DAW.

See the
`pytheory-vst README <https://github.com/kennethreitz/pytheory-vst>`_
for install steps and known issues. The plugins are a companion to the
Python library; sketch in code, finish in the DAW, or play PyTheory live
from a MIDI keyboard without opening a terminal.
